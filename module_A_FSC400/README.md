# 모듈 A: 산업용 유량계(FSC400) 실시간 관제 및 이력 조회

- **과목:** 인공지능특론세미나 (01반) 기말과제
- **학교:** 한양사이버대학교 일반대학원 기계IT융합공학과
- **학번 / 이름:** 2025300378 / 이민호

설치형 초음파 유량계 FSC400의 데이터를 실시간으로 받아 차트와 목록으로 보여주고, 날짜별 기록을 다시 열어보는 관제 프로그램입니다. 배포용 exe는 Python 없이 실행됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `배포용/fsc400_dashboard.exe` | 관제 프로그램 (단일 파일, 약 66 MB) |
| `배포용/사용설명.txt` | 실행 방법과 옵션 설명 |
| `src/fsc400_dashboard.py` | GUI 본체 (ttkbootstrap + matplotlib, 수신 스레드와 큐 구조) |
| `docs/protocol_FSC400.md` | 매뉴얼 기반 MODBUS-RTU 레지스터 맵과 미확인 사항 |
| `FSC400 매뉴얼 PDF` | 업체 제공 매뉴얼 (설치형 초음파 유량계 FSC400, U-SUP-FSC400-KR1) |
| `samplecode/` | 참고 원본 (`dashboard.py`, `makedata.py`) |
| `_archive_cli/` | 이전 CLI 수집기와 배포 폴더 (보관용, 사용하지 않음) |

## 배포용 exe 사용법

### 실행
- `fsc400_dashboard.exe`를 더블클릭합니다. 창이 계속 떠 있으며 데이터를 수신합니다.
- 연결이 끊기면 3초 후 자동으로 재연결을 시도합니다.
- 장비가 없으면 "연결 실패"가 표시되고 재시도를 반복합니다. 장비 없이 확인하려면 소스를 `시뮬레이션`으로 고르세요.

### 연결 설정 (상단 바)

| 항목 | 설명 | 기본값 |
|---|---|---|
| 소스 | `MODBUS-RTU` / `ASCII 라인` / `시뮬레이션` | MODBUS-RTU |
| 포트 | 장치관리자에서 확인한 COM 포트 | COM3 |
| 보드레이트 | 장비 설정과 같게 맞춤 | 9600 |
| 슬레이브 | MODBUS 주소 (1~247), MODBUS-RTU 전용 | 1 |
| 주기(초) | 수신·기록 주기. MODBUS-RTU와 시뮬레이션에서 사용 | 1.0 |

- **MODBUS-RTU:** 매뉴얼 부록 A 레지스터를 주기적으로 읽습니다.
- **ASCII 라인:** `헤더,유량,적산,에러,유속` 형식의 한 줄을 받습니다. samplecode 방식입니다.
- **시뮬레이션:** 가상 데이터를 만들어 화면과 CSV에 기록합니다.

### 화면 구성
- **수치 카드:** 순시 유량(m³/h), 적산 유량(m³), 유속(m/s), 에러 코드, 마지막 수신 시각
- **차트:** 실시간 순시 유량 최근 300개. 확대와 이동 도구를 사용할 수 있습니다.
- **데이터 목록:** 최신 데이터가 위에 추가되며 최근 200건을 유지합니다.

### 과거 기록 조회
1. 왼쪽 달력에서 파란색 날짜(기록 있음)를 누릅니다.
2. 하루치 차트와 목록이 나타나고, 상단에 "과거 기록 모드"가 표시됩니다.
3. 차트를 클릭하면 목록에서 가장 가까운 시점의 행이 선택됩니다.
4. 목록은 500건씩 나누어 보며 `◀ 이전`, `다음 ▶`으로 이동합니다.
5. `실시간으로 돌아가기`로 실시간 화면에 복귀합니다.

- 과거 조회 중에도 수신 데이터는 계속 기록됩니다.
- 오늘 날짜는 기록 파일이 생긴 뒤에만 선택할 수 있습니다.
- 미래 날짜와 기록이 없는 오늘 날짜는 선택할 수 없습니다.

### 생성되는 파일 (exe와 같은 폴더)

| 파일 | 내용 |
|---|---|
| `data\flow_log_YYYY-MM-DD.csv` | 일별 기록. 1초 주기, 한 줄당 한 샘플 |
| `settings.json` | 마지막으로 시작할 때 사용한 연결 설정 |

CSV 열 구성은 다음과 같습니다.

```
Timestamp, Header, Flow_Rate(m3/h), Total_Flow(m3), Velocity(m/s), Error_Code
```

## 개발 환경 실행

Python 3.12 기준입니다.

```
pip install ttkbootstrap matplotlib pyserial
python src/fsc400_dashboard.py
```

## exe 빌드

중간 산출물은 `%TEMP%`에 두고, 결과만 `배포용` 폴더에 만듭니다.

```
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name fsc400_dashboard ^
  --distpath 배포용 --workpath %TEMP%\pyi_a --specpath %TEMP%\pyi_a src\fsc400_dashboard.py
```

## 검증 현황

- **프로토콜:** MODBUS 프레이밍(CRC-16, 요청 생성, 응답 파싱)과 워드 순서(CDAB) 디코딩을 매뉴얼 예제 값으로 확인했습니다. 예를 들어 `82 D0 44 FE`는 2036.087890625로 디코딩되어 매뉴얼 값과 일치합니다.
- **GUI 동작:** 시뮬레이션 수신, 목록과 차트 갱신, 일별 CSV 기록, 과거 기록 로드, 페이지 이동, 차트 클릭 연동을 자동 스크립트로 확인했습니다. 화면 캡처로 레이아웃도 확인했습니다.
- **exe:** 실행 후 충돌 없이 창이 유지되는 것을 확인했습니다.
- **미확인:** 실제 FSC400 장비 연결과 ASCII 라인 장비의 출력 형식은 시험하지 못했습니다.

## 알려진 제한

- **에러 코드:** MODBUS 레지스터 맵에 에러 코드가 없어 `N/A`로 표시됩니다.
- **ASCII 라인 형식:** samplecode의 형식이며 실제 장비 출력과 일치하는지 확인이 필요합니다.
- **MODBUS 측정 간격:** 9600 bps에서 1초 주기 폴링이 안정적인지 실장비 확인이 필요합니다. 매뉴얼은 응답 시간을 0.2초로 명시합니다.
- **측정 시각:** 레지스터 맵에 측정 시각이 없어 기록 시각은 PC 수신 시각입니다.
