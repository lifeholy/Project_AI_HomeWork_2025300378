FSC400 초음파 유량계 실시간 관제 (fsc400_dashboard.exe)

[실행]
- fsc400_dashboard.exe 더블클릭 → 창이 계속 떠 있으며 데이터를 수신합니다.
- 실행 파일과 같은 폴더에 data\ 폴더(일별 CSV)와 settings.json(연결 설정)이 생성됩니다.

[연결 설정]
- 소스
  · MODBUS-RTU : FSC400 매뉴얼 부록 A 방식 (기본값). 1초마다 레지스터를 폴링합니다.
  · ASCII 라인 : "헤더,유량,적산,에러,유속" 한 줄씩 수신하는 장비용 (samplecode 방식)
  · 시뮬레이션 : 장비 없이 가상 데이터 생성 (CSV 기록 포함)
- 포트 : 장치관리자에서 확인한 COM 번호 (예: COM3)
- 보드레이트 : 장비 설정과 동일하게 (출고 기본 9600)
- 슬레이브 : MODBUS 주소 (출고 기본 1), MODBUS-RTU 전용
- 주기(초) : 수신·기록 주기 (MODBUS-RTU, 시뮬레이션에서 사용)
- [▶ 시작] / [■ 중지] 버튼으로 수신을 켜고 끕니다.
- 연결이 끊기면 3초 후 자동으로 재연결을 시도합니다.

[화면]
- 수치 카드 : 순시 유량, 적산 유량, 유속, 에러 코드, 마지막 수신 시각
- 차트 : 실시간 순시 유량 (최근 300개). 확대·이동 도구 사용 가능
- 목록 : 최신 데이터가 위에 추가됩니다 (최근 200개 유지)

[과거 기록 조회]
- 왼쪽 달력에서 파란색 날짜(기록 있음)를 클릭하면 그 날의 이력을 불러옵니다.
- 차트 전체 기록을 보여주며, 차트 위를 클릭하면 목록에서 가장 가까운 시점의 행이 선택됩니다.
- 목록은 500건씩 나누어 보며 [◀ 이전] [다음 ▶]으로 이동합니다.
- [실시간으로 돌아가기]로 실시간 화면에 복귀합니다. 과거 조회 중에도 수신은 계속 기록됩니다.
- 오늘 날짜는 기록 파일이 생긴 뒤에만 선택할 수 있습니다.

[CSV 형식 (data\flow_log_YYYY-MM-DD.csv)]
Timestamp, Header, Flow_Rate(m3/h), Total_Flow(m3), Velocity(m/s), Error_Code
- 하루 단위 파일이며 1초 주기로 한 줄씩 기록됩니다.

[참고]
- MODBUS-RTU의 에러 코드는 매뉴얼 레지스터 맵에 없어 "N/A"로 표시됩니다.
- ASCII 라인 방식은 장비의 실제 출력 형식과 일치하는지 확인이 필요합니다.
