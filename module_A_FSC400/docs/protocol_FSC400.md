# FSC400 통신 프로토콜 정리

- **출처:** `설치형 초음파 유량계 FSC400.pdf` (U-SUP-FSC400-KR1, 버전 1, 2024년 7월) 6장 메뉴 63·OCT·RS485 항목, 부록 A
- **범위:** 업체가 제공한 자료가 이 매뉴얼이 전부임. 아래 내용은 매뉴얼에 적힌 사항만 정리했고, 매뉴얼에 없는 항목은 "미기재"로 표시함.

## 1. 통신 설정

| 항목 | 값 | 근거 |
|---|---|---|
| 물리 계층 | RS485 (단자 485A / 485B) | 5.6절, 그림 28 |
| 프로토콜 | MODBUS-RTU | 5.6절, 부록 A |
| 출고 기본 시리얼 설정 | 9600 bps, n(패리티 없음), 8 데이터비트, 1 스톱비트 ("9600 n 8 1") | 메뉴 62 |
| 출고 기본 슬레이브 주소 | 1 | 메뉴 46 |
| 프로토콜 선택 | 메뉴 63: 0 = 제조사 전용(출고 기본값), 1 = 호환 프로토콜 | 메뉴 63 |
| 사용 기능 코드 | 0x04 (Read Input Registers) | 부록 A |

- 제조사 전용 프로토콜(63 = 0)이 기본값이며, 부록 A 레지스터 표는 이 설정 기준으로 보는 것이 자연스러움. 다만 매뉴얼에 "0 = 자사 전용"이라고만 적혀 있을 뿐 구체적인 차이는 설명하지 않음.
- 기타 프로토콜은 "제조사 문의"라고 되어 있음.

## 2. 데이터 표현

- **float:** IEEE754 단정밀도, 워드 순서 **CDAB** (수신 바이트 [C D A B] → big-endian ABCD로 재배열 후 해석)
- **uint32:** 두 레지스터, 순서 **CDAB** (앞 레지스터가 하위 워드로 해석되는 것으로 보임. 매뉴얼 예제 `00 C9 00 00` → 201로 해석)
- **uint16:** 단일 레지스터, 단위는 표 참조

### 검증 결과 (매뉴얼 예제 재계산)
- 응답 바이트 `82 D0 44 FE` → 재배열 `44 FE 82 D0` → float **2036.087890625** (매뉴얼 최종 값과 일치, 구현 `decode_cdab_float`로 확인)
- 매뉴얼 본문의 "메모리 순서 44FED082"와 "203.087890625"는 오기로 판단. 44FED082를 디코딩하면 2038.5가 되어 최종 값과 맞지 않음.

|---|---|---|---|---|
| 0–1 | 순간 유량 | float | m³/h | CDAB |
| 2–3 | 순간 열량 | float | GJ/h | CDAB (열량 옵션) |
| 4–5 | 합산 누적 유량 정수부 | uint32 | m³ | CDAB |
| 6–7 | 정방향 누적 유량 정수부 | uint32 | m³ | CDAB |
| 8–9 | 역방향 누적 유량 정수부 | uint32 | m³ | CDAB |
| 10–11 | 합산 누적 열량 정수부 | uint32 | GJ | CDAB |
| 12–13 | 정방향 누적 열량 정수부 | uint32 | GJ | CDAB |
| 14–15 | 역방향 누적 열량 정수부 | uint32 | GJ | CDAB |
| 16 | 합산 누적 유량 소수부 | uint16 | 0.001 m³ | |
| 17 | 정방향 누적 유량 소수부 | uint16 | 0.001 m³ | |
| 18 | 역방향 누적 유량 소수부 | uint16 | 0.001 m³ | |
| 19 | 합산 누적 열량 소수부 | uint16 | 0.001 GJ | |
| 20 | 정방향 누적 열량 소수부 | uint16 | 0.001 GJ | |
| 21 | 역방향 누적 열량 소수부 | uint16 | 0.001 GJ | |
| 22–23 | 예비 | — | — | |
| 24–25 | 순간 유속 | float | m/s | CDAB |
| 26 | 수위 높이 | uint16 | mm | |
| 27 | 배터리 전압 | uint16 | mV | |
| 28 | 열단 온도 | uint16 | 0.01 ℃ | |
| 29 | 냉단 온도 | uint16 | 0.01 ℃ | |
| 30 | 열단 저항 | uint16 | 0.1 Ω | |
| 31 | 냉단 저항 | uint16 | 0.1 Ω | |

| 36–37 | AI2 대응 물리량 | float | — | CDAB, 단위 미기재 |

- 매뉴얼 예제 요청 `01 04 00 00 00 28 F0 14`는 주소 0부터 40개 레지스터를 읽음 (응답 바이트 수 0x50 = 80).
- 유량 값은 정수부(uint32)와 소수부(uint16)가 분리 저장됨. 합산 값 = 정수부 + 소수부 × 0.001 (예제: 201 + 481 × 0.001 = 201.481 m³).

## 4. 사용 시 주의점 (프로젝트 설계 관련)

- **시간 정보 없음:** 레지스터 맵에 측정 시각 레지스터가 없음. 메뉴 60에 날짜·시간 설정이 있으나 매뉴얼에 해당 레지스터 주소는 나오지 않음. 수집 PC의 타임스탬프로 기록해야 함.
- **샘플링 한계:** 9600 bps 기준 40레지스터 요청·응답은 약 0.1 s 수준으로 추정됨(요청 8바이트 + 응답 85바이트, 1바이트당 약 10비트 가정). 샘플 데이터 설계(10 Hz)는 실장비 폴링으로는 빠듯함. 매뉴얼의 응답 시간은 0.2 s로 명시됨. 실제 측정은 미확인.
- **일부 항목 미기재:** 예외 응답 코드, 쓰기(0x06/0x10) 지원 여부, 프레임 간격 요구사항, CRC 세부 사항은 매뉴얼에 없음. RTU 표준(CRC-16/MODBUS)을 따른다고 가정.
- **호환 프로토콜(63 = 1):** 매뉴얼에 세부 내용 없음. 필요 시 업체 기술 담당자 문의가 필요함.

## 5. 미확인 사항 (업체 문의 후보)

1. 메뉴 63 = 0(제조사 전용)에서 부록 A 레지스터 맵이 그대로 적용되는지
2. 쓰기 명령 지원 여부 및 예외 응답 형식
3. 측정 시각 또는 샘플 인덱스를 얻을 수 있는 레지스터 존재 여부
4. 권장 폴링 주기와 최소 프레임 간격
5. AI1/AI2 대응 물리량의 단위
