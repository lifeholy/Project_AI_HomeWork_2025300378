# 모듈 D: Windows 서버(AIRBOOK-FAS) 점검·실시간 감시 — Rust 1.0.3버전

- **과목:** 인공지능특론세미나 (01반) 기말과제
- **학교:** 한양사이버대학교 일반대학원 기계IT융합공학과
- **학번 / 이름:** 2025300378 / 이민호

모듈 B(Python, `basecode/`)의 관제 프로그램 `CheckServer.py`를 Rust로 다시 작성한 프로그램입니다. 탭 구성, 임계치 판정, 경보, 점검 배치 실행, 결과 조회, 설정 파일 스키마를 모듈 B와 맞췄습니다.

## 상태

- **소스:** 작성 완료 (`src/`)
- **문법 검사:** `rustfmt`로 모든 파일 통과
- **컴파일·실행 파일:** **아직 빌드되지 않았습니다.** 이 PC에 Windows SDK가 없어 MSVC 링커가 실패합니다. 모듈 C의 "빌드 방법"에 있는 SDK 설치 후 빌드하면 `배포용/checkserver.exe`가 생성됩니다.
- **Python 원본과 차이:** 아래 "모듈 B와의 차이"를 참고하세요.

## 구성

| 경로 | 내용 |

## 기능

- **대시보드:** CPU, RAM, DISK, PROCESS 게이지. 임계치 초과 시 화면이 붉게 바뀌고 경고음이 울립니다. 게이지를 누르면 해당 항목 기준으로 프로세스 탭이 열리고, DISK는 볼륨별 사용 창을 엽니다.
- **프로세스:** 실시간 목록, 열 머리글 클릭 정렬, 감시 대상은 파란색 굵은 글씨, 점유 상위 5개는 빨간색. 이름을 더블클릭하면 실행 파일 경로와 명령줄을 보여 줍니다.
- **점검실행:** 일일 FAS / EAI 점검 배치를 실행하고 출력을 실시간으로 보여 줍니다. 실행이 끝나면 결과 목록이 갱신됩니다.
- **결과조회:** 날짜별 실행 결과 폴더를 고르고 TXT, CSV 결과를 봅니다. CSV의 상태 값(PASS, FAIL, WARN)은 색으로 구분합니다.
- **로그:** 누적 로그(최근 1000줄)를 보고 검색합니다.
- **설정:** 감시 프로세스, 임계치, 감시 드라이브, 경고음 사용, 감시 주기, 시간 동기화 명령, 배치 경로를 바꾸고 저장합니다. 저장하면 `userset.json`에 기록됩니다.
- **단축키:** F11로 전체 화면을 전환합니다.

## 실행 파일 사용법

- `checkserver.exe`를 실행합니다. 일부 기능(서비스·프로세스 상세 정보)은 관리자 권한이 필요할 수 있습니다.
- `userset.json`은 **exe와 같은 폴더**에 있어야 합니다. 없으면 기본값으로 자동 생성됩니다.
- 첫 실행 시 `C:\checkPMI\`에 기본 점검 배치 2개(`F100-2-001.bat`, `F100-1-001-DETAIL.bat`)가 없으면 만듭니다.
- 생성되는 파일
  - `C:\checkPMI\logs\<yyyymmdd_hhmmss>\check_result.txt` / `.csv`: 점검 결과
  - `C:\checkPMI\logs\system_accumulated.log`: 누적 로그
- 이 프로그램은 Windows 전용입니다 (`cmd`, `kernel32 Beep`, 한글 폰트 경로 사용).

## 모듈 B와의 차이

- 감시 주기, 임계치, 경고 판정, 로그 기록 시점은 모듈 B와 같습니다.
- **사용자 이름 열 없음:** sysinfo 0.30 기준으로 프로세스 소유자를 바로 가져오기 어려워 상세 창에서는 생략했습니다.
- **결과조회 달력:** Python의 달력 위젯 대신 날짜 입력과 전날·다음날 버튼으로 바꿨습니다. 기록이 있는 실행 시각은 목록에서 고릅니다.
- **창 크기:** Python 버전은 400×400 기본 창이었지만, Rust 버전은 1000×720으로 열립니다.

## 알려진 제한

- 내장 점검 배치 스크립트와 `userset.json`에는 **내부 IP 주소가 그대로 들어 있습니다.** 과제 보안 기준상 공개 저장소에 올리기 전에 마스킹해야 합니다.
- 실서버 점검, 경고음, 관리자 권한 기능은 실서버 없이 확인하지 못했습니다.
- 점검 배치 출력은 CP949(한글 Windows 기본)로 해석합니다. UTF-8이면 자동으로 UTF-8로 읽습니다.
